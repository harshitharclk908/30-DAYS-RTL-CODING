---

# 1. Multiplier

## Description

Performs multiplication between two 4-bit inputs.

### Files

- multiplier.v
- tb_multiplier.v

### Operator Used

```verilog
*
```

### Example

```text
3 × 2 = 6
5 × 3 = 15
7 × 4 = 28
```

---

# 2. Divider

## Description

Performs division between two 4-bit inputs.

### Files

- divider.v
- tb_divider.v

### Operator Used

```verilog
/
```

### Example

```text
8 / 2 = 4
9 / 3 = 3
12 / 4 = 3
```
