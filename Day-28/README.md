# Day 28 - Traffic Light Controller

## Objective

Designed and verified a Traffic Light Controller using a Finite State Machine (FSM).

---

## Concepts Covered

- FSM
- Moore Machine
- State Transition
- Output Logic
- Sequential Circuit Design

---

## States

### RED

Red light ON

### GREEN

Green light ON

### YELLOW

Yellow light ON

---

## State Transition

RED → GREEN → YELLOW → RED

---

## Files

- traffic_light.v
- tb_traffic_light.v

---

## Simulation Results

Successfully verified:

✓ State Transitions

✓ Reset Functionality

✓ Output Logic

✓ Clock-Based Operation

---

## Key Learning

- FSM controls sequential behavior.
- State transitions occur on clock edges.
- Output depends on current state.
- Traffic controllers are common FSM applications.
