# 30 Days Verilog + RTL Coding Challenge

## Objective

A structured 30-day journey to learn Verilog HDL, RTL Design, FSMs, Datapath Design, Verification, and Processor Basics.

---

## Topics Covered

### Week 1

- Logic Gates
- Dataflow Modeling
- Behavioral Modeling
- MUX / DEMUX
- Encoder / Decoder
- Adders / Subtractors
- ALU

### Week 2

- Flip-Flops
- Registers
- Counters
- FSM
- Traffic Light Controller

### Week 3

- RAM
- ROM
- FIFO
- Barrel Shifter
- Multiplier
- Divider
- Generate Blocks
- UART

### Week 4

- SPI
- I2C
- RISC-V Datapath
- Pipelining
- Mini CPU
- Verification
- Mini Project
